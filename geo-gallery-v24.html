Geo Gallery Setup

Setup stays open alongside the gallery — change something, hit Refresh, and see it happen right away.
One column only — combining more than one column here doesn't produce a working image link, so this is a plain column picker rather than a combinable template.
Title, Category, Description, Author(s) and Image attribution can each combine more than one column, plus your own text — e.g. {Story Title} — {Country}. Type {ColumnName} directly, or pick one from "+ insert column" to add it without typing the exact name. Description also supports multiple lines (press Enter) and the Bold/Italic/Underline/Link buttons above its box.
Auto-detected from the category column once a CSV is loaded — click a swatch to change a colour, edit the text next to it to change what that tab says (the underlying data it matches is unaffected), or drag a row by the ⋮⋮ handle to reorder the tabs.
Four clear options rather than a long list. All are free and need no account, so the map never breaks for someone else viewing a shared gallery.
Paste a hex code directly here — colour swatches themselves usually can't accept a paste.
Colour of the title/subtitle text itself, separate from the background behind it.
A small, self-contained set — no fonts are downloaded, so this never depends on the internet connection of whoever's viewing the gallery.
PNG, JPG, or animated GIF. Uploading embeds the image directly (as a data URL), so keep it under ~200KB — a shared/saved gallery carries this file's full weight every time it's opened. A URL to an already-hosted image avoids that entirely.
Makes the logo clickable — e.g. your organisation's homepage. Leave blank for a plain, non-clickable logo.
"All" is the default first tab, showing all images.
Category tabs use their own colour automatically. The "All" tab isn't a category, so it needs its own — black by default, but change it here if you'd rather it matched your header, or used a light background with dark text.
Apply, Save configuration and Load configuration are pinned at the top of this panel, alongside Refresh and Undo, so they're always in reach without scrolling. Configuration is column mapping, colours and header text only — a small file to reuse on another CSV with the same columns. It doesn't include the photos themselves; for a self-contained, shareable gallery with the data included, use Share via Gist below.
Editable links let recipients open Setup and change anything. View-only links hide Setup entirely — the restriction is embedded in the saved data itself, not just the link, so it can't be bypassed by editing the URL. Diagnostics stays available either way, so anyone can report a problem.
