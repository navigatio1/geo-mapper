## 🎯 WHAT'S NEW

### **1. Chart Settings Now Restore Properly** ✅ FIXED

**The Problem:**
- When reloading a saved session, time-series chart settings weren't restored
- Users had to manually re-select time field and value field
- Warning appeared: "⚠️ Select both time field and value field"

**The Fix:**
- Chart dropdowns now populate BEFORE settings are restored
- All chart settings (type, fields, custom labels, titles) restore correctly
- No more manual re-configuration needed!

**Affected Settings:**
- Chart type (Bar Chart / Time-Series)
- Selected data fields
- Custom chart titles
- Custom bar labels
- Time field selections
- Value field selections

**Result:** Seamless session restoration for chart users! 🎉

---

### **2. School-Friendly Security Updates** 🔒

**The Problem:**
- Tectonic plate overlay loaded from `raw.githubusercontent.com`
- Many schools block this domain (security policy)
- Overlay would fail with no fallback

**The Fix:**
- App now tries LOCAL file first: `navigatio.earth/map/PB2002_boundaries.json`
- If local file unavailable, falls back to GitHub
- Better error messages explaining firewall blocks
- Helpful instructions for IT managers

**Benefits:**
- ✅ Works behind school firewalls
- ✅ Faster loading (local file)
- ✅ Less dependent on external services
- ✅ Clear error messages if both sources blocked

**Action Required:**
Upload `PB2002_boundaries.json` to your `/map/` folder (see instructions)

## 🚀 DEPLOYMENT INSTRUCTIONS

### **For GitHub Pages Users:**

**1. Update the Map App:**
```bash
# Option A: Web Interface
1. Go to: https://github.com/YOUR_USERNAME/geo-mapper/tree/main/map
2. Click: index.html → Edit (pencil icon)
3. Replace ALL content with v2.7.0 file
4. Commit: "Update to v2.7.0 - Security fixes"

# Option B: Git Command Line
cd /path/to/your/repo
cp /path/to/new/geo-point-mapper.html map/index.html
git add map/index.html
git commit -m "Update to v2.7.0 - Security fixes and chart restore"
git push origin main
```

**2. Upload Tectonic Plates File (Recommended):**
```bash
1. Download: PB2002_boundaries.json
   URL: https://raw.githubusercontent.com/fraxen/tectonicplates/master/GeoJSON/PB2002_boundaries.json
2. Upload to: /map/ folder in your repo
3. Commit: "Add local tectonic plates data"
```

**3. Upload IT Manager Guide (Optional):**
```bash
1. Upload: IT_MANAGER_SECURITY_GUIDE.md
2. Location: Root of repo (for easy reference)
3. Share URL with IT department for approval
```

**4. Wait & Test:**
```bash
1. Wait 1-2 minutes for GitHub Pages rebuild
2. Visit: https://your-domain.com/map/
3. Hard refresh: Ctrl+Shift+R
4. Check version: Should say "v2.7.0" in header
5. Test chart restore: Upload CSV → Configure chart → Reload page
6. Test tectonic plates: Enable overlay (should work!)
```
